# 公式、结构与回归校核

用于多公式、文字层 PDF、分栏、脚注绑定或章节重组。依据原图裁定，以下是判断依据，不是固定坐标、字号或数量。

## 原生字符与公式

- 保留原始字符编码、字体／字形名、字号、基线、bbox、可取得的真实墨迹边界与绘图线。嵌入字体中的字符码可能错指字形；控制字符、乱码或问号不能直接当成原文，也不能统一替换成连字。
- 分清文本斜体和数学变量。标题、英文单词与说明采用文本字体；单字母变量、希腊字母和算符依据字形与上下文处理。规范 fi／fl 等连字时保留实际词间距。
- 分数依据分子／分母的横向覆盖、垂直层级及真实分数线判断。先统一算符的语义，包括 `−` 与 `-`、`≤`、`±`；不能仅修一种编码。负号后的上下堆叠不应输出为负号的上下标，也不能把 `\mathbb{Z}_2^5` 等字母基底上的真实上下标改为分数。
- 横线不只修饰字母，还可能覆盖数字、负数或整个表达式。区分上划线、分数线、根号横线及表格线；用墨迹和相邻基字定位，不能只比较发音符号的文字框。
- 根指数、根号、大括号、矩阵括号、乘积及直和的上下限按二维位置整体归属。公式区域跨两个正文块时，解决归属，不让一个重音符触发整式 OCR 插入另一个段落。
- 只含上划线／波浪重音／撇号等片段不足以采用识别器的整条公式。简单公式原生重建后与复杂 OCR 核对；冲突回原图。缓存识别结果以便复核，不因排版改动重识别整书。
- 集合条件竖线用 `\mid` 等关系间距；绝对值、基数、范数单独分类。不全局把每个 `|` 改成 `\mid`。保留括号、声明标签和数学片段边界的可见空格。
- 多行计算使用 `aligned`／`alignedat` 等自然测量行高；文字说明用 `\text{...}`，必要时局部分行。不要靠压扁分数、负行距或固定小行高制造紧凑效果。
- 清楚的原书数学印刷错误也不应静默改写。忠实转录，在不影响正文的校对记录中说明；用户要求纠错时再修改内容。

## 图表、分栏与注释

- 字符分配优先明确的列、单元格、题注和公式所属块，再按基线聚合。每个有效字形分配一次的检查能发现漏字／重复，但不能证明行列语义正确；同时抽查原图及关键条目。
- 索引先识别原图列数与各列起点，考虑镜像边距造成的整列偏移。依原列顺序合并真正续行，保留子项层级和页码；孤立页码先查前一词条，不随意删除。
- Notation 按“符号—解释”对应，不按纯文本一行拼接。上下限和展开式属于符号本身，不能流入相邻说明行。复杂符号可按源图精确重建 TeX，仍须保存原字形覆盖证据。
- 同排多个面板先组成整体区域，再关联居中题注；保留 (a)/(b) 和箭头图例。题注可在上方、下方或侧边。若原图裁剪已包含题注，去掉裁剪中的重复题注再排可编辑文字。
- 原书图可保留清晰矢量裁剪；关键数学公式不默认截图。可准确重建的表格、域塔和码字阵列优先可编辑 TeX。
- 将题注与短图表排在同一个不可拆页块，检查块是否超页；真正长表的分页按用户约束处理。不能用过度缩小来掩盖超页。
- 注号结合字形、大小、位置和原页注释匹配；正文的运算星号不是脚注。只绑定有依据的引用，不把未匹配注释放末段。页底裁切不能吞掉注释的末行。
- 装饰标题、TikZ 节点或 minipage 内的注号，需要避免注释被关进局部盒子。必要时分离 mark/text，仍验证引用和正文同页；不要只验总数。

## 真实层级与移动参数

- 大部分、编号单元、正文主题、习题区和习题分类分别映射适当的 `\part`、`\section`、`\subsection`、`\subsubsection`。定理和例子采用声明或相应环境，Proof／Solution 保持其语义，不滥用章节命令。
- 编号单元从 0 开始或独立篇编译时，显式恢复正确计数；答案中的对应单元是答案下的小节，不能再次改写全书主章计数。
- 标题匹配应有边界，区分完整标题 `Exercises 1` 与正文 `Exercises 1 through 4...`。原来的两个检测块也可能是一条标题，正文跨页后仍归真实单元。
- 短标题保护方括号，例：`\subsection[{The Division Algorithm in F[x]}]{...}`。用能够识别嵌套及转义花括号的解析处理标题；简单正则不适合脚注和嵌套宏。
- 数学标题的目录显示和 PDF 字符串分别处理，例如 `\texorpdfstring{\ensuremath{\equiv}}{≡}`；实际文本字体未必包含关系符号。脚注留在长标题，短标题避免重复注释正文。
- `\@seccntformat` 会预展开。格式包含赋值、字体切换或色块时，用受保护的格式宏；先编译样章。目录罗马页码需要足够的右侧页码宽度。
- 自动目录使用重排后的实际页码；版权、目录和前言按合理边界起页。比较连续编译结果，必要时三遍至稳定，不以“已跑两遍”替代稳定性判断。

## 验证层次

1. **来源与结构：** 实际保留／去重／省略页、跨单元切片、章节及声明编号、注释归属和完整分栏。数量从本书建立，不套用案例数字。
2. **改动范围：** 对当前校订源码做预期差异比较。结构调整保持数学内容；纯隐藏注释调整保持可执行 TeX；系统性分数修复保持其余公式与真正上下标。
3. **构建：** 本次生成完成后才编译。样章失败先修，避免几十篇重复同一错误；公共样式或结构变更再检查全书。检查错误、被忽略的错误、缺字、溢出和未定义引用。
4. **实际页面：** 给注号引用／注释正文、题注／图表起止设标签后比较真实页码。解析 `.aux` 时处理嵌套符号组；渲染受影响页与邻页，检查分数线、行距、标题、面板及页脚。目录中的同名条目不计成第二个正文标题。
5. **交付：** 来源映射与最终 PDF 同步；复制后核对文件与原 PDF 不变。只交付成功验证的版本，保留中间证据但不把虚拟环境、模型缓存及整书图像塞进技能包或普通交付包。

总数匹配、编译成功和抽样图像正确各提供不同证据。明确说明做过的校核，不能宣称仅凭这些已完成全书逐字、逐式人工审定。
