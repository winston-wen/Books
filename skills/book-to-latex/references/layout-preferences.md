# 此用户的排版默认值

适用于未另指定版式的新转换；继续已有项目时保留其已确认参数，最新指示优先。这是个人偏好，不是所有书的统一标准。下表中的中文字体、引文、全网格及节末注释配置来自中文史料项目；西文数学书使用后面的专门配置，不把两者互相覆盖。

| 项目 | 默认处理 |
| --- | --- |
| 纸张 | B5，176 × 250 mm；单面，不区分左右手 |
| 边距 | 左右相同；原双面配置不同时取较大值；本次参考值为22 mm |
| 正文 | 宋体；行距与段间距独立调整 |
| 章、节标题 | 带编号并靠左；中文黑体，西文及数字无衬线，优先 Calibri |
| 引文 | 仿宋，两侧各缩进2字，保留实际分段 |
| 段间距 | 宋—宋、宋—仿、仿—宋及引文内部使用同一段距；参考值为0.35倍基线距离 |
| 节末注释 | 按原书实际分节归属，保留原注号；“注释”标题放大并标出章或节号 |
| 页眉页脚 | 页眉留空；左页脚为章名且用仿宋，右页脚为页码；章首页同样处理 |
| 表格 | 完整外框、全部横竖分隔线；长表允许跨页且重复表头 |
| 表下来源说明 | 靠近表底，局部消除正文段距和长表间距的叠加 |
| 参考文献 | 默认保留原书文字列表，不额外引入 BibTeX |
| 来源注释 | 源码使用原书页码，扫描文件名保存在独立对应表 |

## 集中设置字体

中文字体命令不会自动改变拉丁字母和数字。标题同时设置 `\heiti` 与 `\sffamily`；`\setsansfont{Calibri}` 不影响正文西文字体。目标环境无该字体时用已安装的无衬线替代字体，例如 TeX Gyre Heros，并检查嵌入 PDF 的实际字体。

页脚修改同时覆盖 `fancy` 和章首页的 `plain`；只给左侧章名加仿宋，不把右侧数字一起改掉。

## 统一正文及引文段距

以下为已验证的实现思路，按当前工程环境适配；避免重复定义已有命令：

```tex
\newlength{\BookParSkip}
\setlength{\BookParSkip}{.35\baselineskip}
\setlength{\parskip}{\BookParSkip}
\newenvironment{bookquote}{%
  \list{}{%
    \leftmargin=2em\rightmargin=2em
    \listparindent=2em\itemindent=2em
    \parsep=\BookParSkip\topsep=0pt\partopsep=0pt}%
  \item\relax\quotefont
}{\endlist}
```

`\quotefont` 需事先定义为仿宋。长度在定义时求值，应在正文基线配置适当时设置。不要叠加 `topsep`、`partopsep` 使宋—仿边界比宋—宋更宽。页底对齐的伸缩也会影响视觉距离，必要时检查 PDF 坐标。

“乘2”不是将段距改为整行空白的固定指令；先看原值，并区分额外段距与两段末、首行的实际基线距离。上次整行空白的试版过松，最终采用上面的紧凑统一间距。

## 表格与来源注释

`booktabs` 的三线表不满足完整网格要求。使用带竖线的列格式及每行 `\hline`，把线宽与列间填充计入总宽度，不让新边框造成溢出。

长表后间距可在局部分组内使用 `\setlength{\LTpost}{3pt}` 与 `\setlength{\parskip}{0pt}` 控制。普通表格后的说明可使用局部零段距及 `\par\nointerlineskip\vspace{3pt}`，避免再叠加普通段距。数值是起点，渲染后确认不贴线、不拥挤、不与后文混淆；不要用改变全书段距来修一个表的留白。

## 交付偏好

后续仅更新工程与必要的 PDF；不自动重打书籍压缩包。校对过程本机保留但按请求忽略于 Git。表格、字体或间距修改检查受影响样页即可；需要全书重新分页时更新目录和引用。纯隐藏注释修改用源码不变量验证即可。

## 西文数学书配置

- 继续采用 B5、单面、左右相同边距及左页脚章名／右页脚页码；字号和具体边距沿用当前确认值，不固定沿用某一本书的数值。
- 正文及斜体文字选用支持西文与连字的文本字体，例如 TeX Gyre Termes；公式使用数学字体。不要把整段斜体标题当成数学斜体，不把中文宋体／仿宋／黑体配置套给英文正文。
- 标题保留正常大小写，**不使用小大写**。声明标签从正文左边界开始，与内容明确留空；不设置整段旁注悬挂区。内容写不下时续行回到正文左边界。
- 公式让 TeX 自然测量高度；分数、多行计算及矩阵不得靠固定低行高、压扁盒子或负行距硬塞。
- 集合条件使用 `\mid` 或适当的 `\middle|`；保留绝对值、基数和范数的语义。标点与变量之间依原图保留合理间距。
- 图表保留原书的行列、分隔线、底色和面板结构；西文书不强制改成中文史料的全网格。短表题与表体、图与图题同块，不允许题留前页而内容在后页。真正超页的长表依任务要求处理，并重复题注／表头；不能缩到无法阅读来假装同页。
- 页脚注留在引用所在页。不要把图形盒子里的脚注变成局部 minipage 注释，也不要拿数学运算星号充当注号。
- 原书编号单元用 `\section` 等真实层级命令。章内主题和习题区使用 `\subsection`，计算、概念、理论等分类使用 `\subsubsection`；原书未编号的小标题默认不额外显示编号。前后文与大部分按实际结构处理。
