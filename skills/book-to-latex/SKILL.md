# 书籍 PDF 转 LaTeX 与校订

交付可继续编辑、可编译且能追溯原书的工程。初次转换和后续修订采用不同路径：已有校订稿时直接修改当前 `.tex`，不要重新生成整本书。

## 接手任务

- 读取用户的转换说明、原书目录、工程说明和现有编译入口。区分用户明确要求、书中内容及 OCR/Markdown 后加内容；后加评论、现代译文不自动进入原书。
- 盘点输入、输出和已完成校订。原始扫描只读，保留旋转、裁切等处理的工作副本。
- 记录当前书的章、节、注释与插图清单作为基准；从实际材料建立数量，不沿用其他书的数据。
- 排版任务读取 [个人排版偏好与实现](references/layout-preferences.md)。该配置属于此用户的默认偏好，当前任务的新要求优先。
- 此用户禁止运行 **Windows MinerU**。确认实际 WSL 发行版、Linux MinerU 与构建入口后使用；不能因找不到 Linux 环境而转用 Windows 版。复用已有环境与识别缓存，不把某次虚拟环境或模型版本的绝对路径当作前提。并发、CPU/GPU 根据已授权环境和资源确定，不通过弹出调试窗口启动后台转换。

## 输入类型与转换路径

先判断 PDF 是扫描图、有可靠文字层，还是混合输入。扫描书以原图和 OCR 交叉校对；有文字层的西文数学书优先使用原生字符、嵌入字体字形、基线、实际墨迹边界和 PDF 绘图，复杂或缺失公式再用 Linux 公式识别。文字层本身也可能编码错误，不能把复制出来的字符直接视为原文。

涉及多公式、分栏、图表或章节重组时，读取 [公式、结构与回归校核](references/math-and-structure.md)。其中的识别阈值、书籍数量和案例页码不能作为新书的硬编码条件。

## 来源页码与结构

建立“扫描文件 → 原书页码或无页码位置”的映射。前言、目录和正文可能独立编号；书签、彩页、漏扫空白页、重复拍摄会改变偏移量。按页脚证据及连续区间核验，不能对整书套一个固定差值。

确认重复扫描时，核对页面内容和印刷页码；正文只收一次，原始文件及映射保留。没有印刷页码的图片页按内容命名，不虚构页码；推定页码与实见页码在映射中区分。

正文每章一个 `.tex`，表格可独立文件。隐藏来源注释使用 `% 原书第117页`、`% 原书第117–118页`、`% 原书前言第2页`；不以扫描文件名充当原书页码。文件与页码对应表另存为来源元数据。

依据原书实际标题划分章、节及附录边界，不机械照搬扫描区间或 OCR 标题。同一来源页可能跨两个单元：边界前归前一篇，边界后归后一篇，不能重复整页或丢掉前章续文。前后文合篇、白页剔除等特殊规则按本书要求执行；仅因内容少不能判为空白页。

使用实际 `\part`、`\section`、`\subsection`、`\subsubsection` 等命令表达层级，让目录和书签由结构生成；不要只画出类似标题的文字。保留原书单元及定理编号；是否显示新小节编号由用户要求和原书体例决定。定理、例子、证明、习题题号及表格列名不自动升级为章节标题。

区分页脚注与节末注释。中文史料原有节末注释按实际节归属，章首导言注释单独归属；原有页脚注绑定正文标记并留在该标记所在页。保留原注号或符号，不把所有注释统一移到节末，也不把无法绑定的脚注随意附到最后一段。

## 交叉校对

以扫描图为底本，有第二份 OCR（如 MinerU Markdown）时结合使用以定位差异，回图裁定。来源注释或排版的小改动不以 OCR 齐全为前提。OCR 之间一致也不证明正确。先检查内容和结构，再调整视觉样式：

- 漏行、漏段、重复段、跨页断句、注号归属及章节边界。
- 引文起止及跨段连续关系，包括奏折、朱批、诗词和图中的纯文字文告。
- 表格逐格的行列、合并关系、表题、来源注释。不能只恢复表题而遗漏表体；可编辑重建优先。
- 图片、图注、正文指向关系、下划线和其他有内容意义的格式。
- 中英文括号、书名号、引号的类型和嵌套。中文行文中的人名括注用全角，英文书目和罗马字转写内部括号通常用半角；英文撇号不能当作中文引号批量替换。字符数量平衡不足以证明配对正确。

用户确认字形后直接采纳，记录确认依据并从待辨认项移除。保留原书清楚的异体字和历史用字；现代写法可记在校对记录，不自动替换底本。

**确认是字符但认不出字时，严禁删除。** 原图中高度确信是一个字符的视觉符号，必须在原位置保留：能准确编码时保留该字符；认不出时以一个全角方框 `□` 占位，西文可使用半字宽框。多个字符按可确认的数量逐个占位，数量不明时明确标记范围不确定；记录原书页码、位置与待辨认项。不凭上下文猜字，也不能因为删字后句子仍通顺而接受空缺。OCR 未返回字、罕见 CJK 字、异体字、兼容字符或字体缺字均不是删除理由。

字符识别、编码与排版缺字分别处理：字体不支持时补用可用字体或绘制可见占位框，源码及校对记录保留原字符。LaTeX 可用绘制框的命令实现全角／半角占位，不能以空字符串、空格、隐藏注释或 PDF 缺字留白替代。所有清洗、替换、格式转换及导出都必须保留这些占位；最终渲染检查占位可见。校对姓名和引文时特别检查连写字符被 OCR 静默漏掉的情况。

## 修订与验证

只做当前请求需要的改动。已校订的 `.tex` 是权威正文，原始 OCR、初始 blocks 数据不是；不要重跑会覆盖校订的生成器或历史一次性修复脚本。

批量改动先在内存中完成映射、目标和边界验证，再写入；逐文件保存变更日志，以免中途失败后丢失已完成记录。重试时识别已转换内容，避免重复变换。若当前工程把注释另存结构化数据，内容变更后同步相关数据。

识别器或生成器修复先在副本、明确受影响的章节中验证，并与当前校订源码比较预期差异；只有能保留既有校订时才采用生成结果。标题重组比较数学与正文不变量，分数修复核对确切目标及邻近真正上下标。发现一种系统性错误时检查同类，但不要扩大到无关版式或把一次局部修订变成整书重识别。

生成、编译、校核和复制是有依赖的步骤。工具返回运行中或会话 ID 时等待实际完成并检查退出状态，再执行后一步；生成失败后不得用旧 PDF 宣称成功。中断恢复先确认正在运行的进程、已成功写入的阶段和备份，不重复批量替换已处理内容。

- 可见内容或排版变更：使用已有 XeLaTeX 构建入口，编译至交叉引用稳定；检查错误、缺字、溢出、浮动体和未定义引用。渲染本次影响的实际页面，核对表格、引文、节末注释、标题或页脚后交付。
- 先验证小样或样章，再扩展到受影响文件。公共导言、全书层级或全局版式变更需要全书检查；小改动不重复检查已确认且未受影响的部分。自动目录从干净工程构建时可能需要三遍，最终以目录、引用和页码稳定为准。
- 编译退出码为零不是唯一验收依据，还要读缺字及被忽略的诊断。页码、分栏、字形和公式语义需独立校核；记录检查范围，不把通过编译当作数学或文字无误。
- 注释迁移：逐章、逐节核对正文引用与注释定义的对应及归属，不仅检查总数相等。
- 段距调整：先读取当前长度、伸缩量及列表环境附加距离。固定段距为零时，直接乘二没有意义；说明采用的视觉解释，先检查样页。字体相邻边界要求相等时，核对基线间距，并去除环境额外留白。
- 仅改隐藏来源注释：只改真实 `%` 注释，保留 `\%`；比较修改前后可执行 TeX，确保相同。无需为不可见改动重建 PDF。

编译成功不等于逐字校勘完成。准确说明检查范围，不把交叉 OCR 或抽样回图说成全书逐字人工审定。

## 工程维护与交付

优先沿用已有工具、字体和构建环境；此用户在 Windows 上优先使用现有 WSL。不要把某台机器的绝对路径或某次插件版本写成运行前提。单文件文档可使用宿主内置编译器；多文件书籍使用工程构建入口。

校对证据、OCR 中间产物、缓存和一次性脚本可由 `.gitignore` 排除；编译必需源文件、图片、可复用构建脚本及来源元数据保留。忽略不等于删除，也不能自动取消已跟踪文件；先检查 Git 状态，再按用户要求处理。

默认更新源工程及必要的 PDF，不再自动更新书籍压缩包；用户明确要导出时再打包。排版只做用户要求的迭代，不把所有产物重建或全套检查作为每次小改动的固定步骤。

最终用简短中文交代改动及验证结果，链接实际产物。页数由最终编译结果读取，不把历史页数作为固定验收值。

本技能累积自实际书籍转换；仅在需要理解具体教训时读取 [案例边界](references/case-notes.md)。
