# 《真事隐》LaTeX 工程

这份工程按用户提供的《转换说明.md》转换 499 张扫描件，以扫描版本为底本。已逐章与“真事隐”目录下的 MinerU Markdown 交叉比对，差异回看扫描裁定。第一、二章 Markdown 中的 8 段明确标记的读者评论已插入对应位置，以独立圆角虚线框区分；现代译文及独立补充考据文章未并入原书。书中七章各有一个 `.tex` 文件；跋、四篇附录、后记和参考文献分别保存。

## 编译

在此目录运行：

```bash
bash build.sh
```

脚本优先使用 PATH 中的 XeLaTeX；在本机 WSL 内会自动找到 `C:/texlive/2026/bin/windows/xelatex.exe`，连续编译三遍，生成 `真事隐-B5.pdf`。也可在支持 XeLaTeX 的编辑器中打开 `main.tex` 编译。所有 LaTeX 输入和图片采用工程内相对路径，移动整个工程目录即可继续编译，不需要重新执行 OCR。

Windows 可运行 `build.cmd`。MiKTeX 或 TeXLive 均可，需已安装 `ctex`、`fontspec`、`hyperref`、`caption`、`subcaption`、`longtable`、`xurl`、`tcolorbox`、`amsthm` 等常用包。

## 排版与内容

- B5：176 × 250 毫米。页面不区分左右手，左右边距均为 22 毫米。正文行宽按新纸张重排。
- 章、节标题均靠左，正文节采用 `1.1`、`1.2` 等编号；“注释”标题用四号黑体，注明所属章或节。
- 章、节及注释标题的西文和数字使用 Calibri，无此字体时回退至 TeX Gyre Heros。中文行文括号用全角，西文文献及满语转写内部括号用半角，两端保持配对。
- 页眉留空，原页眉内容固定在页脚左侧并使用仿宋，页码固定在页脚右侧，章首页同样适用。
- 正文段间距与宋体、仿宋引文交界间距统一使用 `\BookParSkip`（0.35 倍基线距离），引文环境不额外叠加上下留白。
- 引文用仿宋，两侧各缩进两个字。Windows 使用系统仿宋；其他系统使用 TeXLive 自带的 Fandol 仿宋。
- 读者注释、批注和评论使用 `comment` 环境：白底、细灰虚线、圆角矩形框，内容用小号仿宋，可自动跨页。Markdown 原文件保留，框内文字与原书正文分开。
- 685 条原书注释按实际分节放到节末，沿用各章原始编号，正文上标可跳转到对应注释。章首没有节标题的导言，其注释放在导言末。
- 按用户确认的实际分节：“太子好不了的病”收录第六章注释 129–146；“君臣对立与选太子”收录 147–158。
- 参考文献仍为书末独立文字列表，保持原书分组和次序，没有使用 BibTeX。
- 扫描 138 的比较表重排为可编辑的跨页表格；扫描 341 的表2“入藏官兵石刻”恢复为6行4列表格；扫描97的八字表保留原书无编号样式。
- 正文表格采用完整网格线，绘制外框和所有行列分隔线；跨页比较表续页重复表头并闭合边框。
- 扫描335的文告按原图7.2重排为可编辑的仿宋引文图片；扫描349–352的9则请安折及朱批逐则排为引文。
- 扫描259/260、384/385分别是原书238页、363页的重复拍摄，正文各仅收录一次；跋和附录一依实际标题分界。
- 图片统一连续编号为“图片”；扫描 36 的原印票和电脑释文拆为两个子图。
- 扫描 1、2、14、499 直接成页；扫描 88–91 作为 2 × 2 的“原书书签”，排在扫描 14 和重排目录之间。
- 倒置的扫描 22、42、144、175、201、261 在 OCR 输入中旋转 180°，原始扫描文件未修改。
- 保留扫描版版权页所载的 2026 年 3 月第 2 次印刷信息。

各正文段落及注释前用 `% 原书第…页` 标明原书印刷页码，前言另标为“原书前言第…页”，无页码插页注明其名称；`sources/printed-page-map.csv` 保留原始扫描文件与原书页码的对应关系，可返回原件校对。`qa/crosscheck-*.json` 记录本轮正文交叉核对、结构修复及保留的底本异文；`qa/audit.json` 为初次 OCR 的低置信度记录。已进行全文双向文字比对及重点扫描复核，尚不等同于逐字人工校勘。当前校订正文以 `.tex` 为准；`ocr/`、`processed/`、`sources/blocks.json` 保留初次识别过程，不是校订后正文。

后续直接编辑 `.tex` 文件即可；`tools/build_book.py` 是本次转换时的生成器，重新运行会覆盖章节 `.tex`，不要在手工编辑后随意运行。普通编译只需 `build.sh` 或 `build.cmd`。

新增评论写法如下；可选参数沿用 `tcolorbox` 的样式键，例如局部设置 `colback=gray!3`：

```tex
\begin{comment}
评论内容。可分段，也可用 \url{https://example.org} 插入链接。
\end{comment}
```

归纳所得的规律可使用 `law` 环境，按章编号为“定律 1.1”“定律 1.2”等，新章重新计数。标题靠左，中文黑体、西文及编号无衬线，内容保持宋体正体。方括号中的名称可省略；加 `\label` 后可用 `\ref` 引用：

```tex
\begin{law}[观点名称]\label{law:viewpoint}
这里陈述关键观点。
\end{law}

参见定律~\ref{law:viewpoint}。
```

不需要编号时使用 `\begin{law*}[观点名称] ... \end{law*}`。第一章与第七章已有的两条读者归纳观点均使用 `law` 环境，现有引用标签保留。

原图中确认存在但暂时认不出的字符，严禁删除。使用 `\UnclearCJK` 保留一个全角方框，西文可使用 `\UnclearLatin` 保留半字宽框；每个实见字符分别占位，并记录原书页码和待辨认位置。这两个命令直接绘制框线，不依赖字体中的方框字形。字体缺字也必须保留字符或显式占位，不能用空白代替。

日常校订只更新工程文件和 PDF，不再同步更新压缩包。`.gitignore` 忽略 OCR、校对证据、一次性转换及检查脚本、临时环境和编译中间产物；正文、表格、图片、最终 PDF 及来源元数据仍纳入版本管理。被忽略的校对文件保留在本机。
